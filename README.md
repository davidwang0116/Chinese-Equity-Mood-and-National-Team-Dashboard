# A股情绪与救市资金仪表盘 · Chinese Equity Mood & National Team Dashboard

> 仿照 [nasdaq-mood-dashboard](https://github.com/davidwang0116/nasdaq-mood-dashboard) 的“恐慌轴 + 回撤轴 → 定投倍数”框架，
> 用 A 股可免费获取的数据源做市场情绪汇总，并尝试识别“救市资金 / 超大资金”的入场足迹。

---

## 架构：数据与计算分离

```
fetch_all.py   ← 唯一联网的脚本（AkShare），写入 data/*.csv 快照 + data/fetch_report.json
     │
     ▼  （以下全部只读 data/，可离线运行、可在沙盒里回测）
indicators.py  原始指标（回撤、RSI、布林、参与度、成交热度、两融、QVIX…）
national_team.py 救市资金足迹 → 强度 0-100 → 叠加方式（观察/验证/并列）
scoring.py     锚点插值 → 子分 → 恐慌轴/估值轴 → 综合分 → 倍数
model.py       串成流水线
backtest.py    IC 检验 + 定投回测 + 权重网格（样本内/外）+ 救市资金事件研究
render.py / main.py → docs/index.html（可开 GitHub Pages）
```

GitHub Actions（`.github/workflows/update.yml`）北京时间周二至周六 08:30 自动（上一交易日数据均已发布）：抓数 → 单测 → 回测 → 生成仪表盘 → 把
`data/`、`reports/`、`docs/` 提交回仓库。也可以在 Actions 页面手动运行，并只抓指定数据源。

## 指标

| 轴 | 指标 | 数据源（AkShare 函数） | 恐慌方向 |
|---|---|---|---|

| 恐慌轴 | QVIX（300ETF 期权隐含波动率，A股版 VIX） | optbbs `index_option_300etf_qvix` → 50ETF 备源 | 越高越恐慌 |
| 恐慌轴 | 市场参与度：沪深300成分股站上 200 日线占比 | 中证成分 + 个股后复权日线 `stock_zh_a_hist` | 越低越恐慌 |
| 恐慌轴 | RSI(14)（Wilder，同通达信） | 沪深300 | 超卖越恐慌 |
| 恐慌轴 | 布林带偏离（距20日中轨 σ 倍数） | 沪深300 | 跌破下轨越恐慌 |
| 恐慌轴 | 成交热度：两市成交额 5日/250日 | 上证综指+深证成指成交额 | “地量”偏恐慌、天量偏贪婪 |
| 恐慌轴 | 融资余额 20 日变化率 | 东方财富 `stock_margin_account_info` → 上交所备源 | 去杠杆越恐慌 |
| 参考 | 股债利差、沪深300 PE、大盘拥挤度、120日新高-新低 | 乐咕乐股 | 仅展示/参与 IC 检验 |

当前权重（`config.json`，v2，由回测选定）：恐慌轴 = QVIX 20% + 参与度 20% + RSI 15% + 布林 15% + 成交热度 15% + 两融 15%；
估值轴 = 回撤 30% + 股债利差 70%；综合 = 恐慌轴 30% + 估值轴 70%。缺失的数据源会自动剔除并重新归一化权重。

## 回测结论（2012-05 → 2026-09，510300 后复权，详见 `reports/backtest_report.md`）

- **估值（股债利差）是 A 股最有效的单一指标**：60/120 日 IC 0.25/0.38，且在 2010-15、2016-19、2020 后三个阶段都为正。
- **单独的回撤在 A 股不是好的买点信号**：各阶段 IC ≈0 或为负（A 股熊市持续时间长，跌深后常继续跌）。
  回撤保留在估值轴（30%），但主要靠股债利差区分“跌了且便宜”与“跌了但不便宜”。
- 估值轴构成对比（网格中位数，样本内/样本外超额 IRR）：只用回撤 0.21/0.20pct → 回撤30%+利差70% 0.47/0.47pct → 只用利差 0.56/0.56pct。
- 恐慌轴的子权重怎么调差别都很小（样本外 0.72–0.74pct），恐慌轴整体权重越低越好：短期情绪/技术指标对 20-120 日
  定投收益的增量有限。RSI、布林、参与度的 IC 接近 0；成交热度（地量）、两融去杠杆、真实 QVIX（2019 后）IC 为正。
- QVIX 免费源只有 2019-12 以后；用已实现波动率回填更早年份的 IC 为负（2015 上半年牛市也是高波动），因此不回填。
- 当前配置：全样本超额 IRR +0.38pct、平均成本 −3.4%；近 5 年 +0.41pct。
- 注意：2012 年以来股债利差大部分时间处于历史高位，所以 ≥1.5× 的日子约占 57%，比纳指版更频繁。
  如果希望“多数日子 1.0×”，可以把 `multiplier_bands` 的 60 上调到 70。

### 救市资金的角色：验证（confirm）

| | 足迹日 | 60 日收益 | 同样承压无足迹日 60 日收益 |
|---|---|---|---|
| 2020 年前（2015-06、2016-01 等） | 7 天 | −15.9% | +0.8% |
| 2020 年起（2020-02、2024-01、2025-04 等） | 10 天 | **+7.6%** | +0.5% |

- 识别器能抓到已知的救市事件：2015-06-29、2016-01-05（熔断）、2020-02-03、2024-01-18、2025-04-07。
- 足迹出现在低点当天或附近，**不是领先信号**；2015-16 救市初期市场又跌了约 17%。
- 2020 年后（尤其汇金 2025 年明确“类平准基金”定位后）足迹之后的收益显著更好，因此作为**验证**：
  近 5 日有足迹且综合分 ≥55 时倍数上调一档。**并列**（并入综合分）在两段样本都拖累收益，不采用。
- 事件数很少（2020 后 5 段），这个结论需要随新事件持续检验。

倍数档位同纳指版：0–60 → 1.0×，60–80 → 1.5×，80–100 → 2.0×。

## 救市资金 / 超大资金

免费数据看不到汇金/证金的交易，只能看“足迹”：

1. **宽基 ETF 净申购**（份额变化 × 价格）：汇金主要通过申购沪深300/上证50/中证500/1000/科创50/创业板
   等宽基 ETF 入场，这是最直接的证据。上交所份额可按日回填（2023 起），深市只能每天快照逐日累积。
2. **宽基 ETF 成交额占两市成交比例的异常放大**：历史最长（2012 起），能覆盖 2015 救市、2016 熔断、
   2018、2024-02、2024-10、2025-04 等事件。
3. **盘中深跌后收在日内高位**（尾盘拉升 / 护盘）。
4. **托权重**：中证1000 大跌时沪深300 明显抗跌。

2–4 只在“市场承压”（回撤 ≥8% / 近5日跌 ≥4% / 当日跌 ≥2%）时计分，避免把牛市放量误判为救市。

**角色怎么定？** `backtest.py` 同时跑三种方式：

- `observe` 观察：只展示，不影响倍数
- `confirm` 验证：近 5 日有足迹且综合分 ≥55 时，倍数上调一档
- `parallel` 并列：强度作为一个分项并入综合分

再结合事件研究（足迹出现后 20/60/120 日收益 vs 同样承压但无足迹的日子；足迹出现在低点之前还是之后），
在报告里给出建议角色。先验判断：救市资金是**反应式**的（跌透之后才出手），更可能适合“验证”而非领先信号，
所以默认 `mode = "confirm"`，以回测结论为准再调整。

## 已知局限

- 参与度使用**当前**沪深300成分股回溯，早年存在幸存者偏差。
- 盘中运行时（北京时间 15:30 前）自动丢弃当日未完成的 K 线。
- 东方财富 ETF“最新份额”实为上一交易日口径，已按上一交易日记账，且只用于深市 ETF（沪市用上交所数据）。
- 乐咕乐股的沪深300 PE 接口当前报错、大盘拥挤度 2026-07 后为空，仅作参考展示，不影响评分。
- 东方财富个股接口在 GitHub 境外机器上失败，参与度走腾讯备源；首次全量约 67 分钟，之后增量更新。
- ETF 份额只能从 2023 年起回填（上交所），深市 ETF 从部署日开始累积；更早的救市事件只能靠 2–4 号足迹。
- 东方财富大单/超大单资金流只提供最近约 120 个交易日，已逐日累积到 `data/market_fund_flow.csv`，暂作观察。
- 北向资金 2024-08 起不再披露每日净买入，未纳入。
